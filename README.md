# NexaMart

A modern e-commerce storefront built with HTML, CSS, and JavaScript.

NexaMart provides a clean and responsive shopping interface where users can browse products, explore categories, sort items, and manage their shopping cart.

## Features

- **Responsive Design** - Adapts to different screen sizes.
- **Product Catalog** - Displays products with images, descriptions, categories, and prices.
- **Product Sorting** - Sort products by featured items, price, and name.
- **Shopping Cart** - Add products, update quantities, remove items, and view the subtotal.
- **Product Categories** - Explore products across different categories.
- **Modern UI** - A clean design with warm beige backgrounds and brown accents.
- **Mobile Navigation** - Navigation designed for smaller screens.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

1. Clone this repository or download the project files.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Project Status

NexaMart is a frontend e-commerce project built for practicing and demonstrating web development skills.

The current version uses demo product data and a frontend shopping cart. It does not yet include a backend, real user authentication, payment processing, or a live order management system.

## Future Improvements

- Connect a backend and database.
- Implement user authentication.
- Integrate a secure payment provider.
- Add product search and filtering.
